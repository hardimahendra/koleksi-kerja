# Koleksi Kerja — Next.js

**Live demo:** https://koleksi-kerja.vercel.app

Modernisasi shopping-cart (proyek lama) sebagai etalase perangkat frontend-only.

- `npm install` lalu `npm run dev`
- Endpoint demo: `GET /api/products`
- Keranjang hanya hidup selama halaman aktif; tidak ada checkout atau pembayaran.
